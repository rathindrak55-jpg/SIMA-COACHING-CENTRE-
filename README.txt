SIMA COACHING CENTRE WEBSITE
=============================

Files:
- index.html
- style.css
- script.js
- logo.jpg

How to use:
1. Open index.html in a browser to preview the website.
2. In script.js, replace 919999999999 with the coaching centre's WhatsApp number.
3. In index.html, replace the placeholder address/phone/WhatsApp information.
4. Upload all four files to any web hosting service to make the site live.

The design is responsive for mobile and desktop.
